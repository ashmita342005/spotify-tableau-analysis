# spotify-tableau-analysis
An interactive Tableau data visualization project analyzing the Spotify 2023 dataset. Features a multi-tab workbook containing individual worksheets (Top 10 Artists, Release Year Trends, Audio Features), a combined analytical dashboard, and a 3-point guided Tableau Story detailing key streaming trends and audio insights.
